# Font Awesome - Kit to Json

[![License](https://img.shields.io/badge/License-MIT-blue.svg?color=2563e8&style=for-the-badge)](https://github.com/ArchLeaders/Revrs/blob/master/License.md)

Converts a FontAwesome kit to an info.json file including every icon.

## Usage

```sh
FontAwesome.KitToJson <kit-path> --output|-o OUTPUT
```
